# Contributing to Legion

## License

Legion is licensed under **MIT**. Your contributions will be released under the same license.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a branch for your changes
4. Make your changes
5. Submit a pull request

## Code Standards

- **Rust stable toolchain**
- Run `cargo clippy` -- no warnings
- Run `cargo test` -- all tests pass
- Run `cargo fmt` -- all code formatted
- **No unsafe** unless absolutely necessary and documented
- **UUIDv7** for all IDs

## What We Value

- Clear code over clever code
- Tests that prove behavior, not tests that prove coverage
- Small PRs that do one thing well
- Commit messages that explain why, not what

## Reporting Issues

Open an issue. Include:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Your platform (macOS, Linux, Windows)

## Questions

Open a discussion or find us on the bullpen.
